## Context

Pantagruel Research necesita un flujo reproducible para validar, publicar y
difundir artículos técnicos desde su repositorio propietario. La publicación
completa pertenece al blog; LinkedIn recibe una versión resumida con una imagen
y un enlace al artículo completo.

Esta tarea histórica está terminada y se conserva en
`pantagruel-alpha/pantagruel-research` porque el sitio, el corpus editorial y
sus skills viven en este producto.

**Skills:** `personal-app` (primary); `documental-contribution` (complementary)

**Traceability:**

- Contribution: contrato histórico trasladado desde el repositorio coordinador
  `pantagruel`.
- Branch / worktree: no registrada.
- Pull request: no registrado.

## Contract

### Functional Specification

- Validar el funcionamiento de Pantagruel Research de extremo a extremo.
- Mantener una skill de publicación del artículo completo en el blog.
- Generar una versión resumida para LinkedIn.
- Adjuntar al menos una imagen a la publicación de LinkedIn.
- Situar el enlace al artículo completo en el primer comentario.
- Extender el flujo únicamente a redes expresamente acordadas.
- Validar el proceso con evidencia observable.

### Technical Specification

La implementación se rige por las instrucciones y las skills locales de
publicación y difusión del repositorio. Las credenciales y cuentas externas
quedan fuera del contrato versionado.

### Validation

- [x] El ownership editorial está atribuido a `pantagruel-research`.
  - [x] La iniciativa histórica se conserva como completada.
  - [x] El traslado no ejecuta publicaciones ni expone credenciales o evidencia
        privada.
